# 技术开发博客：跨性别男性 HRT 模型的 PBPK 对齐之旅

> 日期：2026-11-03 · 仓库：Oyama-s-HRT-Tracker · 伞形 Issue：#215

## 0. 背景与目标

本项目是一个激素替代疗法（HRT）追踪器，其中**女性化 HRT（transfeminine）模型**已经相当成熟：多给药途径雌二醇 PK、SHBG 动态、校准、验证一应俱全。而**男性化 HRT（transmasculine）模型**仅 v1.0（`transmasc_hrt_modeling_document.md`），且 `logic.ts` 已不再引用它——功能差距巨大。

用户提出的目标：**把 transmasculine 模型拉到 transfeminine 的同等水平**，并回答"PBPK 还差多远"。我先在 PubMed 上检索了 PBPK 缺口（睾酮制剂、口服 TU/鼻用/埋植、红细胞压积、SHBG/游离睾酮、子宫/卵巢、性腺切除、GnRH、非那雄胺、药物相互作用），然后创建了 Issue #215（23.6k 字符），包含 A–I 缺口分析、LaTeX ODE 公式、10 阶段路线图、预测表（分室模型对齐 6–9 个月；真正 PBPK 24–48 个月）与 31 篇参考文献。

## 2. 今天完成的主要工作

### Phase 1 — 多给药途径睾酮 PK
- **1.1 口服 TU**（PR #218）：肠道→门静脉→淋巴转运，首过代谢，食物效应。
- **1.2 鼻用凝胶**（PR #235）：快速吸收 `ka≈2 h⁻¹`，生物利用度 ~8%。
- **1.3 埋植剂**（PR #235）：零级释放，无限寿命（`computeMaxLifetimeH` 特殊处理）。
- **1.4 皮下注射**（PR #235）：注射部位模型，`ka` 半衰。
- **1.5 TU 转运室 / Erlang**（PR #245）：多室 Erlang 分布模拟口服 TU 吸收延迟。

### Phase 2 — 游离/生物可利用睾酮
- **2.1 Vermeulen 公式**（PR #220）：`freeTestosteroneNgDl`、`bioavailableTestosteroneNgDl`。
- **2.2 接线到 SimulationResult**（PR #247）：`concNGdL_T_free`、`concNGdL_T_bio`，供下游 PD 使用。

### Phase 3 — 动态 SHBG
- **3.1**（PR #239）：`shbgSuppressionFactor`（睾酮抑制）+ `shbgCurveCombined`（雌二醇诱导 + 睾酮抑制），500k 蒙特卡洛验证。

### Phase 4 — 性腺切除 / 子宫状态
- **4.1**（PR #228）：`gonadectomyState`，子宫/卵巢存在性作为状态变量，影响残余激素与出血。

### Phase 5 — 红细胞压积 turnover
- **5.1**（PR #222）：`hctStep`，睾酮驱动的红细胞生成，带恢复半衰期。

### Phase 6 — 闭经风险
- **6.1**（PR #224）：`amenorrheaHazard`，睾酮/雌二醇驱动的累积风险 `1 - exp(-Σ hazard·dt)`。

### Phase 7 — 体成分慢变量
- **7.1**（PR #226）：`bodyCompStep`，肌肉/内脏脂肪随暴露缓慢变化。

### Phase 8 — 其他药物
- **8.1 5α-还原酶抑制**（PR #241）：`dhtFromTestosterone`，非那雄胺/度他雄胺。
- **8.2 GnRH 激动剂 depot**（PR #243）：`gnrhSuppression`，脱敏动力学。

### Phase 9 — 校准栈
- **9.1**（PR #249）：标量 EKF（`ekfStep`）、MIPD 剂量调整（`mipdDoseAdjust`）、`integrateTransmascState` 状态积分包装器。

### Phase 10 — 验证脚手架

## 4. 关键技术公式（节选）

- 游离睾酮（Vermeulen）：`freeT = (T - SHBG·bound - albumin·bound) ...`（见 `freeTestosteroneNgDl`）。
- SHBG 联合曲线：`shbgCurveCombined(e2, t)` = 雌二醇诱导 × 睾酮抑制。
- Hct：`hctStep(h, freeT, dt)`，睾酮驱动生成 + 恢复半衰期。
- 闭经：`P(amenorrhea) = 1 - exp(-Σ hazard(totalT, e2)·dt/24)`。
- GnRH depot：`gnrhSuppression(t)`，脱敏动力学。
- DHT：`dhtFromTestosterone(t, inhibitor)`，5α-还原酶抑制。
