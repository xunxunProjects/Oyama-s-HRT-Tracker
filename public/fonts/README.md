# Self-hosted fonts

The OpSec reading view uses **Lora** for prose and **Merriweather** for headings.
Both are licensed under the SIL Open Font License 1.1 (see `OFL-Lora.txt` and
`OFL-Merriweather.txt`).

The files are variable-weight woff2 subsets downloaded from Google Fonts:

- Lora: latin and latin-ext, normal and italic (`lora-*.woff2`)
- Merriweather: latin and latin-ext, normal (`merriweather-*.woff2`)

They are self-hosted so the page makes no third-party font requests and keeps
working offline.
